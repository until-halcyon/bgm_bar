Tistory BGM Bar Generator

MP3 직접 링크로 재생하고, 제목은 유튜브 링크로 연결되는 초소형 투명 BGM 바.

※ 파형은 Web Audio API로 실제 재생음을 분석해 움직여. MP3 호스트가 CORS를 허용해야 분석이 정상 작동해. 자동재생은 브라우저 정책상 사용하지 않음.
※ GitHub Pages 플레이어는 iframe이라 티스토리 본문의 CSS 글자색을 자동으로 상속할 수는 없어. 대신 PLAYER COLOR에 티스토리 글자색 HEX를 넣으면 전체 색을 맞출 수 있어.
